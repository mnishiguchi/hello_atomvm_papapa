# 次に試せること

最初の目標だった **1 台の XIAO で「パパパ」を鳴らし、RESET で再生し直すこと**は確認できました。環境と結果は [動作確認のまとめ](hardware-validation.md) にあります。

仕組みを学ぶなら、次の順で試せます。

1. PC のプレビューと実機の音を聴き比べる。
2. `demo_papageno`・`demo_papagena`・`demo_duet` を切り替え、低音と高音の違いを聴く。
3. [音声再生の仕組み](audio-design.md) を読みながら、音源生成・C の出力・Elixir の制御を追う。

音源取り込み・サンプルレート比較は `feat/audio-import` ブランチで扱います。波形測定、周波数特性や歪みの評価、長時間再生は今後の実験です。

このリポジトリは、1 台のスピーカーでの再生を学ぶ範囲に絞ります。2 台の同期やネットワーク制御は、別の段階で扱います。
